The Municipal Public Park Facility Booking Console Application is a Java-based console project developed using Hibernate ORM and Oracle Database. It allows registration of park facilities and citizens and enables booking creation through a simple console interface. The application uses annotation-based entity mapping and transaction management to perform database operations efficiently. Booking IDs are generated using an Oracle sequence to ensure uniqueness and prevent duplication errors. This project demonstrates practical implementation of Hibernate integration, database connectivity, and layered architecture in Java.
